# kokoro.ai サイト

## セットアップ方法

### 1. ファイルを手元にダウンロード
- `index.html` をダウンロード
- ブラウザで開く（ダブルクリックまたはドラッグ＆ドロップ）

### 2. 変更を加える
Claude Code で html を編集

### 3. 更新を確認
- 最新の `index.html` をダウンロード
- ブラウザで F5（リロード）して確認

## 画像ファイル
以下の画像ファイルをダウンロードして、index.html と同じフォルダに配置：
- `hero.png` - ホーム画面トップ画像
- `greeting.png` - ごあいさつページ画像
- `characters-traits.png` - キャラクター紹介画像
